Describe your ex in one word. The entry is a single word written to `/output/entry.txt`:

**Unsubscribe** — the ex as a mailing list you finally opted out of.

Eleven letters, one word, no explanation, no punctuation tricks. The joke lands at a glance (a former partner reduced to spam you stopped receiving), it is not the obvious insult, and anyone who has ever hit "unsubscribe" — or been ghosted by someone who did — feels the truth in it. Exactly what the judge rewards: a one-word verdict, comic punch, surprise, and recognition.

## Run it

```sh
python3 main.py
```

This writes `Unsubscribe` to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), mode 0644, and prints the same word to stdout.
